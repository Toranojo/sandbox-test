# 運用ガイド：AI美女 × SNS × note マネタイズ

出典：とら🐯AIマネタイズ氏のX投稿（【プロンプト付き】AI美女×SNSでマネタイズするための全体像）を運用チーム向けに再構成したもの。

## 全体像

キレイな画像を1枚作るだけでは収益は生まれない。以下の順序で「型」を作ることが重要。

```
①キャラクターを設計する
②リアルに見える要素を入れる
③同じ人物に見せる
④投稿にストーリーを持たせる
⑤収益導線までつなげる
```

---

## STEP① キャラクターを設計する（画像を作る前に）

最初に決めるのは「誰を作るか」。設定がブレると、1枚1枚はキレイでも「一人の人物」として覚えてもらえない。

### 最初に決める項目

- 名前
- 成人だと分かる年齢
- 髪型・髪色
- 服装の系統
- 仕事
- 趣味
- 性格
- よく行く場所
- 投稿する内容の方向性

### 記入例

| 項目 | 内容 |
| --- | --- |
| 名前 | 美月 |
| 年齢 | 26歳 |
| 仕事 | 都内で働く会社員 |
| 髪型 | 黒髪ミディアム |
| 服装 | シンプルで清潔感のあるコーデ |
| 趣味 | カフェ、読書、旅行 |
| 投稿内容 | 仕事の日常、休日のお出かけ、カフェ、自宅での作業 |

キャラクター設計後は「この人物はどんな毎日を送っているのか？」まで想像する。この解像度が実在感（リアルさ）に直結する。


## STEP② リアルさは「顔」だけで決まらない

「目の大きさ」「顔の形」「髪型」「メイク」だけを詰めても不自然（プラスチック肌）になりがち。リアル感を決める6要素：

```
①光　②カメラ・画角　③肌の質感　④背景　⑤表情　⑥生活感
```

- ❌ 悪い例：「かわいい日本人女性、完璧な顔、超美人、最高品質」→ 誰が・どこで・何をしているかが不明瞭
- ⭕ 良い例：「成人の架空の日本人女性、自然な黒髪、白いTシャツ、朝の窓際で撮影したセルフィー、薄いメイク、自然な毛穴と産毛、少し生活感のある部屋、窓から入る柔らかな自然光、スマートフォンで撮影した実写写真」

現実の写真にある「情報」を足すのがポイント：
- 少し乱れた前髪
- 服にできた自然なシワ
- わずかに左右差のある表情
- 背景に置かれたマグカップ
- カメラを意識していない目線

### 【リアル感を足す末尾プロンプト】

```
自然な肌の毛穴と産毛、
わずかな左右差、
作り込みすぎない表情、
現実的な光と影、
過度な美肌加工なし、
プラスチックのような肌を避ける
```

- [ ] 手指

- [ ] 歯
- [ ] 耳
- [ ] 背景の文字
- [ ] 鏡の反射

## STEP③ プロンプトは「6つの箱」で作る

毎回ゼロから考えず、以下6項目に分けて組み立てる。

```
①人物　②髪型・服装　③場所　④行動・表情　⑤光・時間帯　⑥写真の撮られ方
```

### 例（カフェの画像）

| 箱 | 内容 |
| --- | --- |
| ①人物 | 成人の架空の日本人女性 |
| ②髪型・服装 | ブラウンのミディアムヘア、淡いブルーのシャツ |
| ③場所 | 明るいカフェの窓際 |
| ④行動・表情 | テーブル越しに自然に微笑む |
| ⑤光・時間帯 | 午後の柔らかな自然光 |
| ⑥写真の撮られ方 | 35mmレンズで撮影した自然な実写スナップ |

感覚としては「美女を作って」ではなく「写真を撮った場面を説明する」。

```
あなたはSNS用の写真企画を考える
フォトディレクターです。

実写風の画像シーンを20個提案してください。

・日常生活にありそうな場面

・自撮り、全身、横顔、友人撮影を混ぜる
・朝、昼、夕方、夜を入れる
・過度な露出や性的な場面を避ける
出力形式：
・シーン名
・場所
・服装
・行動
・表情
・光
・完成プロンプト
```

## STEP④ 「固定」と「変化」で同じ人物に見せる

プロンプトを「固定する部分」と「変える部分」に分ける。

- **固定する部分**：年齢、顔の雰囲気、髪型・髪色、肌の特徴、服装の系統、写真全体の色味
- **変える部分**：場所、時間帯、ポーズ、表情、撮影距離、細かい服装

例：「26歳、黒髪ミディアム、落ち着いた雰囲気、薄いメイク」は固定し、「今日はカフェ」「明日はオフィス」「雨の日の駅前」「休日は美術館」とシチュエーションだけ変える。

正面顔のアップだけを並べるのは不自然。以下を混ぜる：
- 顔が分かるアップ
- 自然な上半身
- 全身のコーデ
- 何かをしている横顔
- 風景を含めた後ろ姿

---

## STEP⑤ 画像ではなく「生活」を投稿する

キレイな画像を並べるだけでは「見られて終わり」になりやすい。「どんな人物の、どんな一日なのか」が分かる投稿にする。

- ❌ 悪い例：「カフェに来ました☕️」
- ⭕ 良い例：「新しいカフェを見つけたので、仕事前に少しだけ寄り道☕️ みんなは朝型？夜型？」

ストーリー＋回答しやすい質問を添えることで、見るだけの投稿からアクションを誘導する投稿に変わる。

### 投稿内容の4分類（ミックスして運用）

```
①日常　②趣味・好きなもの　③仕事や目標　④フォロワーへの質問
```

---

## STEP⑥ 画像・発信・収益導線をつなげる

画像のクオリティだけでは収益にならない。以下がつながっているかを確認する。

```
誰に見てもらうか
　↓
何を発信するか
　↓
どんな悩みを解決するか
　↓
どこで収益化するか
```

- 仕事・勉強系キャラクター → AI活用、仕事効率化、勉強法、便利サービスと相性が良い
- 旅行好きキャラクター → 旅行情報、ホテル、旅行グッズ、地域別まとめと相性が良い

画像を作ってから商品を無理やり当てはめるのではなく、上記の流れの中で画像・投稿を作る。

### 本運用における収益導線（note）

- note＝キャラクターの「日記」形式。写真＋テキストで日常を綴る。
- 無料記事で世界観・キャラクターへの興味を作り、有料エリア／有料マガジンで続きの写真・エピソードを提供する。
- 架空の商品体験談・ステマは行わない（下記「注意点」参照）。

---

## デメリット・注意点

1. **毎回同じ顔になるとは限らない**：同じプロンプトでも角度・表情で別人のようになることがある。複数枚生成して選ぶ作業が必須（→ 画像QA工程で吸収）。
2. **画像を作っただけでは収益にならない**：投稿テーマ・プロフィール・収益導線が揃って初めて機能する。
3. **誤解を招く運用は信用が消える**：有名人に似せる、実在人物のように過度に装う、架空の体験談で商品を紹介する等は長期的信用を失うため禁止。

## メリット（このモデルの強み）

- モデルの手配が不要
- 撮影場所が不要
- 多様なシーンを作れる
- 顔出しなしで素材を用意できる
- 改善しながら量産できる
