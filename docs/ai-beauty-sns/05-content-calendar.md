# 投稿カレンダー／ローテーションルール

`04-daily-prompt-workflow.md` で「今日の投稿シーン」を決める際に、このルールと下の投稿ログを必ず確認してから決定する。

## ルール

1. **5日ルール**：直近5日以内に使ったテーマ・シーンは繰り返さない（下の「投稿ログ」で確認する）。
2. **有料コンテンツは3〜4日に1回**のペースで挟む。`characters/001-rio.md` の有料コンテンツ7カテゴリ（①水着 ②自宅ランジェリー ③ナイトアウト/クラブ ④カラオケ・女子会 ⑤温泉旅行 ⑥季節イベント ⑦フィットネス・ヨガ）を、**同じカテゴリが連続しないようにローテーション**させる。季節イベント（⑥）は花火大会・初詣・年末年始など、実際の季節に合わせて使うタイミングを調整する。
3. **無料投稿は日常のバリエーションを意識する**。カフェ・お出かけ系だけに偏らせず、「自宅で料理をした」「ダラダラ休日を過ごした」「洗濯・掃除をした」など、生活感のあるシーンも定期的に混ぜる（`characters/001-rio.md` の投稿テーマ一覧を参照）。
4. 有料コンテンツの当日も、無料SNS側にはテキストのみ／控えめな1枚を投稿し、本編（際どめのカット）は有料noteに誘導する運用は継続する。
