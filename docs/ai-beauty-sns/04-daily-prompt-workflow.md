# 日次投稿プロンプト生成フロー（GPT画像生成向け）

画像生成は運用者（ユーザー）がGPT（ChatGPT/GPT-4o系の画像生成）で行う前提のフロー。プロンプト担当（人／Claude）は「今日の投稿シーン」が決まったら、そのシーンに必要な枚数分の完成プロンプトをGPTに出力させるところまでを担当する。

## 全体の流れ

```
①今日の投稿シーンを決める
    ↓
②必要枚数を決める（無料post/有料noteで目安が異なる）
    ↓
③メタプロンプトをGPTに貼り、シーン別プロンプトをN本生成
    ↓
④生成前チェック（エラー回避チェックリスト）
    ↓
⑤GPTで画像生成 → 画像QA担当（02-team-structure.md）へ
```

---

## STEP① 今日の投稿シーンを決める

以下の「シーン決定シート」を埋めるだけにする（`03-character-brief-template.md` の投稿テーマ一覧から選ぶのが基本）。

| 項目 | 記入例 |
| --- | --- |
| テーマ（投稿テーマ一覧から選択） | 例：夜景スポットでのお出かけ |
| 場所 | 例：都内の夜景が見えるバー街 |
| 時間帯 | 例：夜 |
| 気分・行動 | 例：仕事終わりに友人と一杯 |
| 服装カテゴリ | 日常／カフェ／お出かけ／**リゾート・水着（有料）** のいずれか |
| 公開区分 | 無料post ／ 有料note |

服装カテゴリが「リゾート・水着」＝有料の場合は、`characters/001-mio.md` の「有料コンテンツの範囲」ルールが自動的に適用される前提で進める。

---

## STEP② 必要枚数の目安

| 用途 | 推奨枚数 | 内訳の目安 |
| --- | --- | --- |
| 通常の無料post 1本 | 3〜5枚 | アップ1、上半身1〜2、全身1、横顔/後ろ姿1 |
| 有料note 1記事 | 6〜10枚 | 上記に加えて角度・表情違いを2〜4枚追加 |

同じ文章でも別人のような顔になることがある前提のため、**採用に必要な枚数の1.5〜2倍を生成しておく**（画像QANGでの却下分を見込む）。

## STEP③ メタプロンプト（GPTにそのまま貼るテキスト）

以下をコピーし、`{{ }}` 部分を埋めてGPTに貼る。「①のシーン決定シート」の内容と、キャラクター設計シートの「固定要素」をそのまま渡すのがポイント（同一人物感の担保）。

```
あなたはAI画像生成用のプロンプトを設計する
プロフェッショナルなフォトディレクターです。
以下の情報をもとに、画像生成AI（GPT画像生成）に
そのまま入力できる完成プロンプトを{{必要枚数}}本作成してください。

【キャラクターの固定要素（毎回変えない）】
{{character-brief.mdの「固定要素」をそのまま貼る}}

【今日のシーン】
テーマ：{{テーマ}}
場所：{{場所}}
時間帯：{{時間帯}}
気分・行動：{{気分・行動}}
服装カテゴリ：{{服装カテゴリ}}

【プロンプトの組み立て方（6つの箱）】
①人物　②髪型・服装　③場所　④行動・表情　⑤光・時間帯　⑥写真の撮られ方
の6項目を必ず含め、上記の固定要素（顔・体つき・アクセサリー・私服の系統・
水着の色と形を含む「シグネチャールック」）は水着シーンかどうかに関わらず
全プロンプト共通にしてください。場所・時間帯・ポーズ・表情・撮影距離・
髪型のアレンジ（下ろす/ハーフアップ等）・アウターや小物だけを{{必要枚数}}本の間で変化させ、

　"confident" "natural" "relaxed" 等の中立的な語に置き換える

　（editorial photography / lifestyle photography / catalog photography /
```

## STEP④ 生成前チェック（GPTでのエラー回避チェックリスト）

GPTの画像生成は「実在人物に見えるリアルな人物表現」「性的・扇情的と取られる表現」に対して弾かれやすい。出来上がったプロンプトを画像生成に投げる前に確認する。

- [ ] 実在の有名人・特定個人を想起させる名前や特徴の引用がない
- [ ] 成人（26歳など）であることが伝わる表現が入っている
- [ ] "sexy" "seductive" "sensual" 等の扇情的な形容詞を使っていない（→ "confident" "natural" 等に置換済み）
- [ ] 撮影ジャンルを示す語（editorial / lifestyle / catalog / natural snapshot）が入っている
- [ ] 水着・肌見せカットの場合、"tasteful" "resort/travel editorial" 等のプロ文脈語が入っており、身体の一部を強調するクローズアップになっていない
- [ ] 水着はキャラクター設計シート固定の"solid black"の色・トライアングルビキニの形をそのまま使い、他の色・形になっていない（指定不足はスク水化・紐ビキニ化、"full coverage"の強調しすぎはハイウエスト下着化しやすいため、固定の言い回しを都度使い回す）
- [ ] 私服・アクセサリー（シルバーネックレス＋フープピアス）もキャラクター設計シートのシグネチャールックと一致している
- [ ] 胸元・ヒップを強調するアングルや、カメラに向けた誘うようなポーズになっていない
- [ ] ヌード・性的行為を想起させる構図やポーズの記述がない
- [ ] ブランドロゴ・商標名が入っていない
- [ ] 1プロンプト1シーン（矛盾した行動・状況の混在がない）

> **生成が弾かれた場合の対応方針**：表現を過激にする／隠語で回避する／「どこを直せば通るか」を繰り返しAIに聞きながら試行錯誤して押し通す、といった「フィルタを掻い潜る」方向の修正は**しない**。ポリシー違反の判定が出たら、それは「シーン設計が範囲を超えている」というサインとして受け取り、水着の布面積を増やす・構図をより自然体にする・シーンをより控えめなものに変える、のいずれかで対応する。1〜2回の言い回し調整（露出度・構図を下げる方向）で解決しない場合は、そのカットの採用自体を見送り、`characters/001-mio.md` の「有料コンテンツの範囲」に照らして別のシーンに差し替える。
