## 運用の大前提（コンプライアンス）

- キャラクターは**完全な架空の成人**として設計・明記する（実在の人物・有名人に似せない）。
- **未成年を想起させる表現は禁止**。年齢・見た目とも成人であることが明確に分かる設定にする。
- 過度な露出・性的表現は避ける。有料部分で水着・際どめのカットを扱う場合でも、扱ってよいのは雑誌のグラビア・水着カット程度までとし、**ヌード・性的行為を想起させる構図やポーズは一切禁止**（キャラクター単位のルールはキャラクター設計シートに明記する）。
- 「私も使って効果があった」等、**架空人物による虚偽の体験談・ステマ的な商品紹介は禁止**。
- AI生成であることを偽って実在の人物・専門家であるかのように誤認させる運用はしない。プロフィール等にAI生成の架空キャラクターである旨が分かる表記を入れる。
- 際どめのカットを扱う場合は、**投稿先プラットフォーム（note・X等）の利用規約を事前に確認**し、規約に抵触するものは投稿しない。規約上扱えない場合は成人向けコンテンツを許容する別プラットフォームへの切り出しを検討する。
- 上記に反する投稿・オファーは、収益より先に停止・修正する。
