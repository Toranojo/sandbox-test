# AI美女 × note マネタイズ運用ドキュメント

架空のAI美女キャラクターを軸に、SNS（X等）で認知を広げ、noteの有料記事（日記・写真）へ送客して収益化するための運用資料一式です。

## 運用の大前提（コンプライアンス）

- キャラクターは**完全な架空の成人**として設計・明記する（実在の人物・有名人に似せない）。
- **未成年を想起させる表現は禁止**。年齢・見た目とも成人であることが明確に分かる設定にする。
- 過度な露出・性的表現は避ける。
- 「私も使って効果があった」等、**架空人物による虚偽の体験談・ステマ的な商品紹介は禁止**。
- AI生成であることを偽って実在の人物・専門家であるかのように誤認させる運用はしない。
- 上記に反する投稿・オファーは、収益より先に停止・修正する。
